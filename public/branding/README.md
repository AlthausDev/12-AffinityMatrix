# DesireSync brand assets

- `desiresync-icon.avif`: compact synchronized-wave mark used in square brand slots.
- `desiresync-favicon.png`: reduced icon for browser tabs.
- `desiresync-logo.png`: 800 × 485 full DesireSync logo used by the Profile Hub hero.

The full logo is kept as PNG because the previous AVIF conversion produced a fully transparent image in-browser. The higher-resolution raster provides enough pixel density for the larger desktop hero while the compact icon remains separate for small square placements where the full wordmark would not be legible.
